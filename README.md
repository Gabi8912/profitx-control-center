# PROFITx Control Center

Бесплатный Telegram-бот для фиксации вступлений и выходов из канала.

## Возможности первой версии

- фиксирует новые вступления и выходы после подключения;
- присылает владельцу мгновенные уведомления;
- показывает статистику командами `/stats` и `/today`;
- хранит историю в PostgreSQL;
- работает на Render как web service;
- имеет health-check страницу.

## Важно

Бот начинает собирать данные только после запуска. Он не может восстановить историю
вступлений и выходов, произошедших ранее.

Чтобы Telegram присылал события `chat_member`, бот должен быть администратором канала,
а приложение должно явно запросить этот тип обновлений. В проекте это уже настроено.

## Переменные окружения

- `BOT_TOKEN` — токен BotFather.
- `ADMIN_CHAT_ID` — Telegram ID владельца.
- `CHANNEL_ID` — ID канала в формате `-100...`.
- `DATABASE_URL` — строка подключения PostgreSQL.
- `PORT` — Render задаёт автоматически.

## Команды

- `/start` — запуск и показ Telegram ID.
- `/id` — показать Telegram ID.
- `/stats` — общая статистика.
- `/today` — статистика за последние 24 часа.

## Безопасность

Никогда не добавляйте токен в файлы GitHub. Храните его только в Environment Variables
на Render. Если токен попал в открытый доступ, отзовите его через BotFather.
